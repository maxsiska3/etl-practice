# Spotify Analytics ETL with dbt and DuckDB

## What this project accomplishes

- Seeded a database with a CSV from kaggle *(spotify analytics)*
- Created a Staging Model
- Create Mart models *(currently only have 2)*
- Visualize via Tableau
- Implement Apache Airflow in the future

## Stack

- **Database**: DuckDB
- **Modeling Framework**: dbt-core
- **BI**: Tableau
- **Orchestration**: Apache Airflow *(future not now)*
